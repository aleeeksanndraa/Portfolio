tictaps

skill-based mobile gaming

TicTaps is a skill-based mobile gaming startup preparing for launch — players take on mini-games with friends, create or join parties, enter tournaments and compete using in-game currency or real-money gameplay.

more visuals being added to this case study

01

overview

I joined the project at an early production stage.

TicTaps already had an initial design direction, but the interface needed to feel more modern, consistent and easier to build.

The team needed a cleaner visual direction, a stronger design system and production-ready components for both iOS and Android.

02

challenge

Balancing bold gaming visuals with a scalable design system.

The existing UI was inconsistent and hard to extend. The challenge was making the interface feel energetic and playful while keeping it structured enough to build from — and to hand off cleanly to a development team.

03

process

01

Product audit

Reviewed existing Figma screens, app structure and UI kit to identify inconsistencies and areas that needed to be rebuilt.

02

Flow refinement

Worked with the product manager to map and refine key user journeys across games, parties, friends, leaderboard and wallet.

03

UI redesign

Redesigned existing screens and created new ones with cleaner layouts, stronger hierarchy and a bold gaming visual direction.

04

Design system & handoff

Rebuilt the UI kit with reusable components, tokens and mobile patterns to support development across iOS and Android.

05

ux structure

Browse → Play → Earn

Together with the product manager, we mapped and refined the main user flows — browsing games, joining or creating parties, managing friends, checking rankings and accessing the wallet. The goal was a clear, connected experience with minimal friction at every step.

06

visual direction

Gaming-first — bold, social, energetic.

The product needed to feel gaming-first — bold, social and energetic — while staying structured enough to scale. Bright gradients, neon accents and strong typographic hierarchy give TicTaps its personality without making it chaotic.

07

design system

The UI kit was rebuilt as a scalable design system — logo, gradient and color palette, reusable components and mobile patterns with clear tokens and naming conventions for handoff.

  • Logo, gradient and color palette.
  • Reusable components and mobile patterns.
  • Clear tokens and naming conventions for handoff.

reflection

Working closer to development than usual.

This project made me more intentional about how I structure and name components — small decisions that matter a lot during handoff. Working directly with developers and another designer pushed me to think beyond the screen and consider how the system would actually be built.
